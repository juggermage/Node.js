## 1. Загальна інформація

**Мета:** перевірити відповідність системи критеріям приймання AC-01–AC-18, описаним у README.md.

**Середовище:**
- Node.js / Express
- MongoDB Atlas — `kindergarten_dev`
- Prisma ORM
- Bruno
- Base URL: `http://localhost:3000/api/v1`

Тестування виконується на відповідній гілці Pull Request.

Використовуються лише вигадані тестові дані. Заборонено змінювати або видаляти записи інших розробників.

**Статуси тестування:**
- `Not Run` — тест ще не виконано.
- `Passed` — фактичний результат відповідає очікуваному.
- `Failed` — виявлено невідповідність.
- `Blocked` — тест неможливо виконати через перешкоду.
- `Not Implemented` — функціональність відсутня в перевіреній версії.

Для кожного тесту після виконання потрібно записати фактичний результат, дату, гілку/PR та за потреби посилання на GitHub Issue.

## 3. Додаткові регресійні перевірки

Під час тестування Pull Requests необхідно також повторно перевіряти:

- Soft Delete та збереження історії.
- Відповідність HTTP-кодів актуальній API-специфікації.

Особливу увагу приділити повторній перевірці TC-008 і TC-011 із першого кола.
